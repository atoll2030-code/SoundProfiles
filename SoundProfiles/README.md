# SoundProfiles v1.0

Android-приложение на Kotlin + Jetpack Compose: фиксированные профили «Дом», «Работа», «Улица».

- Короткое нажатие: применение профиля.
- Долгое нажатие: редактирование и сохранение профиля.
- Настройки хранятся локально в SharedPreferences, без root и интернет-разрешения.
- Android 8.0+ (minSdk 26).

## Получение готового APK через GitHub Actions (без Android Studio)

1. Создайте **пустой** репозиторий на https://github.com/new, например `SoundProfiles` (можно Private).
2. Распакуйте ZIP архива и загрузите **содержимое папки SoundProfiles**, включая скрытую папку `.github`, в корень репозитория. На компьютере это удобно через **Add file → Upload files**, перетаскиванием содержимого папки, затем **Commit changes**. Если загружаете через Git, используйте команды ниже.
3. Откройте в репозитории вкладку **Actions → Build SoundProfiles APK**.
4. Нажмите **Run workflow → Run workflow** (либо откройте успешный запуск от push).
5. После успешного выполнения в разделе **Artifacts** откройте `SoundProfiles-v1.0-debug-APK` и скачайте ZIP-артефакт.
6. Распакуйте полученный ZIP: внутри будет **app-debug.apk**. Перенесите его на Android и установите (может потребоваться разрешение установки из выбранного источника).

Важно: GitHub Actions **не запускает сборку, пока файлы не загружены в ваш репозиторий**. APK пока не был собран и не проходил испытаний на физическом устройстве. При первой сборке возможны ошибки, их можно диагностировать по логу Actions.

### Загрузка через Git (альтернатива веб-интерфейсу)

```bash
cd SoundProfiles
git init
git add .
git commit -m "Initial SoundProfiles Android app"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/SoundProfiles.git
git push -u origin main
```

## Сборка в Android Studio

Откройте корневую папку проекта. Используются Android Gradle Plugin 8.9.2, Kotlin 2.1.20, Gradle 8.11.1, Java 17, Android SDK 35. В архиве нет `gradle-wrapper.jar`; для сборки через Actions он не нужен (Gradle устанавливается action-ом). В локальном терминале можно выполнить `gradle :app:assembleDebug`, если Gradle уже установлен.

## Ограничения Android

- На некоторых устройствах уведомления и звонок имеют общий канал громкости, независимую настройку Android не гарантирует.
- Для перехода между режимами звонка Android может потребовать доступ к управлению «Не беспокоить»; приложение выводит запрос на переход в системные настройки.
- Последний выбранный профиль сохраняется, но автоматическое применение профиля после изменения звука другим приложением не предусмотрено.
